# Supplementary tables

Generated by `scripts/make_supplement.py` from the analysis tables that `scripts/make_tables.py` writes
(`reports/analysis/*.csv`), which also generate every number of the paper; nothing here is typed by hand.
Regenerate with `python scripts/make_tables.py && python scripts/make_supplement.py`.

- `supplement.pdf` / `.tex`: one table per model with every state (seed 0), then its per-task scores and retentions.
- `complete_results.csv`: one row per model state at seed 0. Columns: `order` (dense, quant, prune, joint, p_then_q,
  q_then_p), `sparsity_pct`, `bits`, `tcr` = 1 - b/16 (1 - s); `wikitext2_ppl`, `c4_ppl`; `wikitext2_kl` and `c4_kl`
  (KL divergence to the dense model; Qwen2.5-3B has none); `layer_error` (mean normalized layer error E over the
  linear layers); `I_E_pct` (layer interaction of a combination in % of E_P + E_Q, mean over layers, as in Fig. 1);
  `sr3` (semantic retention on ARC-Easy acc, PIQA acc, HellaSwag acc_norm, the paper's Sr) and `sr9` (nine tasks)
  with 95% paired-bootstrap intervals; `I_Sr3` = Sr3 of the combination minus the product of the single methods'
  Sr3, with its interval (Table 2).
- `task_scores.csv`: per state and task, the score with lm-eval's metric (`metric`), the dense model's score and the
  retention score / dense score. Tasks: ARC-Easy, PIQA, HellaSwag (the paper's three), ARC-Challenge, WinoGrande,
  OpenBookQA, BoolQ, SciQ and LAMBADA (OpenAI), full splits, zero-shot.
- `seeds.csv`: WikiText-2 perplexity for calibration seeds 0, 1 and 2 with mean and sample sd.

The layer-level ablations (one shared Hessian, E2; no compensation, E9) are in `reports/analysis/e2_cells.csv` and
`reports/analysis/e9_cells.csv`; the raw result lines are in `results/v2/`.
